# 3D Designing with Fusion 360.

In this documentation, we will explore and practice designing using Autodesk fusion 360.

![Description](https://drive.google.com/thumbnail?id=12UuPOMzddO9BSy0BFGLeQ9YGcZpkL6w9&sz=w800)


## Downloading the software.

there are three ways we can download and install the software.

| Tier         | Target Audience                              | Cost                   | Key Restrictions / Features                                                                                                 |
| ------------ | -------------------------------------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Personal Use | Hobbyists, makers, personal projects         | Free                   | Non-commercial only; 10 active editable documents limit; limited import/export types; basic manufacturing (2D/3D printing). |
| Commercial   | Businesses, freelancers, professionals       | $85/month or $680/year | Full CAD/CAM/CAE toolset, unlimited active documents, unrestricted access to file formats, professional support.            |
| Educational  | Students, educators, qualifying institutions | Free                   | 1-year renewable subscription for academic/learning purposes only.                                                          |

> To know more about the types of subscription for fusion [here](https://www.autodesk.com/products/fusion-360/blog/fusion-subscription-types/)

Once you have any type of subscriptions of any type then you can download the installer and install the software. 
- Fusion360 is a cloud based application where you can design and when you save it the designs are saved on cloud and all these will be associated with your Autodesk Account.


## Interface.

When you open the software, this is how it will look.

![Description](https://drive.google.com/thumbnail?id=150oVsjbtZo74oIs63QdCl6xIh_yNmHud&sz=w800)

1. This Panel can be collapsed and it can show all the project files and folder you have with your autodesk account.
2. The number 2 indicates the workspace to make your design.
3. These are the tools you can use to zoom, pan etc while woorking on your design.
4. This is your work timeline where every design and edit will be recorded.
5. Account detail and notifications related to your autodesk account.
6. This is the navigation cube, rotating the cube will rotate the design on your workplane. 

## Sketching

To start making your design, in fusion360 every shape startes with a sketch drawn on a profile.

1. First start by clicking on the create sketch icon at the top as shown and labeled below as 1.

![Description](https://drive.google.com/thumbnail?id=1FVkzZkBuQ2nlEkMBEnpGbEu_n79v__K3&sz=w800)

2. Once you have selected the create sketch then you need to select the plan where you want to make tge sketch.

![Description](https://drive.google.com/thumbnail?id=1yuoDTa6u3snL8KD5rRbKQGQIZL_6pxFK&sz=w800)


3. Once you have you are in scetch format, you will notice that even the interface will also change. In this mode we will be able to make 2D sketches.

![Description](https://drive.google.com/thumbnail?id=1AZhkP8T62hPBf1fI6V7_aUVeU9aTomX3&sz=w800)

4. Now inside this sketch mode we will make a square or a rectangle as shown below:

![Description](https://drive.google.com/thumbnail?id=14DztOaU1iQ3UkWdQsjaIor5G8XAuaCXs&sz=w800)

- you can click on the rectangle icon as labeled 1 above.
- Once you click on the type of shape you want then a side panel specific to the shape will appear and for this design purpose I will be using centre rectangle.
- Then we can click at the origin as the centre of the rectangle and drag or give dimensions as per the requirment. You can shift from length to width by click on tab button.
- Once the dimension is done you can click Enter.

## Modifying

### Edit Sketch

To create a sketch with equal ratio offset on all side we can use the offset feature.

![Description](https://drive.google.com/thumbnail?id=1U9pJJrY7q3pbbDmPHiDghKsADhdH1Bdy&sz=w800)

1. Click the offset tool from the menu
2. Select the reference sketch
3. Drag the line inside or
4. Define the offset length.
5. Click OK

After clicking ok, we can see a new sketch inside our original sketch.

![Description](https://drive.google.com/thumbnail?id=1B4GFtF5B44--Rg_etHbxmwwqI4iA2KOw&sz=w800)

- Then once your done you can click on Finish to complete the edit.

### Editing New Body.

Now that we have our 3D model with edges and faces. Similar to making sketches in on the XYZ plane, we can also make sketches on a face of one of the side of the 3D model.

![Description](https://drive.google.com/thumbnail?id=1zXFMoKGuEoUystb4JURYc8G1uRQmCVkK&sz=w800)

to create sketch on the face (indicated by 1 in the image above), we can select the face and click on the create sketch on the top left corner (indicated by 2 in the image above)

![Description](https://drive.google.com/thumbnail?id=1UwNhNrwpwrtdwFezjfj30Gl8o4Yl438v&sz=w800)

once we enter the sketch mode, the interface will change to sketch mode where we can make the sketch and since this time we will make the circle.
1. click and selct the circle option.
2. On the right hand side you can select the type of circle you want to make. (Centre Diameter Circle or Two-Point Circle or Three-Point Circle or Circle based on tangent)
3. Then you can select the type of line (you want to make a construction lin or profile line)
4. Then select the center point of the circle and drag or give dimensions as per the requirment.

![Description](https://drive.google.com/thumbnail?id=1VYFb4xEEXtMs33uiSK49F4ArQjmOGUm6&sz=w800)

for this design we will make a center diameter circle and set the diameter to 30 mm as shown above.

![Description](https://drive.google.com/thumbnail?id=1mbAJorqUH7bzWoRYFGeZ8aPHTHP_MZLj&sz=w800)

Then we want to make a hole from the center of the circle to the base of the object using the extrude tool. To extrude and make a hole
1. Click 'E' to enable the extrude option
2. Select the circle profile
3. drag the arrow downwards to make a hole. (You can also use the arrow to adjust the depth of the hole)

![Description](https://drive.google.com/thumbnail?id=1iM-KCUY2EKSS-cwhbMPIoj9atQTSns6d&sz=w800)

In the above image, you will notice on the right side indicate the cut operation therefore where ever you drag the arrow the solid material will be removed from the object. (Indicated by a Red Color)

### Section Analysis

To view the solid object in a cross-section we can use the section analysis tool. 

![Description](https://drive.google.com/thumbnail?id=11Zq3Jccqg1hH9ewWwI7kbZSr1JHGE81e&sz=w800)

1. Click on the Inspect tab in the top menu bar.
2. Click on the Section Analysis tool.
3. And select the face or plane you want to use to show the section.

![Description](https://drive.google.com/thumbnail?id=11Zq3Jccqg1hH9ewWwI7kbZSr1JHGE81e&sz=w800)

once you have slected the slicing plan then you can drag it to adjust the section to a desiable location.

![Description](https://drive.google.com/thumbnail?id=1AIcHbBDHr7ZX9nOXTRnVVaRDTqoq5lIH&sz=w800)

The image given shows the section part of the model.

![Description](https://drive.google.com/thumbnail?id=1iEZAOMtESc6FW4UxyNXswd3GFEVIy-ET&sz=w800)

1. Origin : This will shown the XYZ plane and the origin
2. Section : Once you have created a sesction then you will see the section.
3. Body : What ever 3D model you create, it will be listed here.
4. Sketches : Whatever 2D sketches you make make will be listed here.
5. The number five shows the sketch that we had created in the begining.

**You can toggle the eyeball to make the object/sketch/origin visible or hide it**

## Creating new Body

Now if we want to create a new body that is seperate from the previous body we made. Therefore for this activity we will make a lid for the containner.

![Description](https://drive.google.com/thumbnail?id=1ibq1IBrONRTI9tSm-FBNNMns2kHKGJv6&sz=w800)

To make a solid object, we first need a 2D profile to extrude from. And as shown above we dont have a profile to extruce from but we can use the shape and make 2D profile.

### Projection 

We will make use the project feature of the sketch mode and for that we cna click on the key 'P' and then slect the face where you want to project.

![Description](https://drive.google.com/thumbnail?id=1ThSxduGuT3inhbY8cVpGJIpL0rfL9qH5&sz=w800)

Once you click the P key and then you can select the face you want to project. Once you have selected the face and then you can click OK and this will project the profile on the plan you have selected.

![Description](https://drive.google.com/thumbnail?id=16zRyC3ZJW7b5b79H1UorbKtPuednjzfc&sz=w800)

after projection is done you will see a purple lines around the edge of the base. These purple lines are the projected profiles. Click finish sketch and then you can start seeing the profile to select and make a new solid body.

![Description](https://drive.google.com/thumbnail?id=17hNHxnO0-qPi6yqieqRLcO-SYGc4zToz&sz=w800)

you can hover over the projected surface and now you will be able to select the face to extrude.

### Extruding new body.

Now that we cane select the faces, to make the lid we will press 'E' and then select the two faces.

![Description](https://drive.google.com/thumbnail?id=1Uk9EDC_-EacToHxHXw9a3Sd55GI4TGaW&sz=w800)

**Note : Do not forget to change the operation from Cut to New Body**

![Description](https://drive.google.com/thumbnail?id=1y0yuA9RjReVHlV9ZgUUy6CDlP1gNoP1e&sz=w800)

Now you can toggle the **Hide Bodies** to hide the container body and you can see the lid created. or you can enable the section so that you can see the inside part better.

Now since will also have a internal hollow space where the lid will sit in, we will use the sketch that we had made using the projection mathod earlier. You can enable the visibility of the sketch using the eyeball icon.

![Description](https://drive.google.com/thumbnail?id=1gOIY9aoSFbdmE-Mbn5wmznKKsApAsU9d&sz=w800)

**Note : Do not forget to change the operation from Cut to New Body. Also drag the arrow slightly outside like shown in the image**

After you are done creating two new bodies that we can use to make the lid by using the combine feature.

![Description](https://drive.google.com/thumbnail?id=1iwhwZyJQetZFpkqHEU27R8M5nGPjdhI4&sz=w800)

Once you click the combine tool, you will see a dialog box where you can select the Target Body and the Tool Body. Once both the bodies are selected then you can click ok and the two bodies will be combined.

![Description](https://drive.google.com/thumbnail?id=1J2M6lJIGPBq9u6b-juLZw_mG8G4VLUP2&sz=w800)

Now that we have our lid completed and next we can make a fixed base for the box at the opposite side of the Lid.

![Description](https://drive.google.com/thumbnail?id=1vOtrY2HxdQGfzUMYiGLxUE04424gxITu&sz=w800)

We will follow the same steps as we did earlier that is by using the projection method to have a profile to select and then excrude it.

![Description](https://drive.google.com/thumbnail?id=1hYUu_gTPS5GUq5ZPkb4kAclXFqkOrZmh&sz=w800)

In this case, since we have to make sure it is a enclosed one therefore make sure to select both the profile (the wall and in the inside space). and for this purpose we will select the operation as join so that the new body is connected with first body.
