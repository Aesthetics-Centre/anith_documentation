## Dimension

Before you start making a model, it is important that you make sure you have consider the dimension of the model (Inside and ourside)

![Description](https://drive.google.com/thumbnail?id=1HNp6jf76mnjMYRd4d51TOixm92xetxoE&sz=w800)

## Pattern

For the boundary pattern we can make a sketch on a plan and draw the lines to make a profile face which we can extrude to make it in a 3D form.

![Description](https://drive.google.com/thumbnail?id=1ZIkDZKqoJ7YiiJvLLG62dINCLmtB0zVo&sz=w800)

After you have made a pattern in a single pattern at one corner then we can using the mirror feature to reflect the design to both X and Y axis.

![Description](https://drive.google.com/thumbnail?id=1Nk1dlHNV9UK4zREd9cfZRwfn7P7dEkOa&sz=w800)

- On the right side you can see a panel where we can highlight the sketch object (lines which we want to mirror)
- Then you can draw a line or use the origin plan to indicate the mirror plane.

Then once you have mirror the pattern with respect to two plan then you can select the face of the pattern and Extrude (E) it to the required thickness and click ok.

![Description](https://drive.google.com/thumbnail?id=1YPbDEvy0o8cIbSFyuRs1TAfbDT0idYph&sz=w800)

Then once you are done extruding the pattern then you can see the 3D model of the pattern as shown below:

![Description](https://drive.google.com/thumbnail?id=18wwAxlngXjJ3IFFjD8iKygTRvo5ZYF3F&sz=w800)

## Layout

Then once you have the 3D bodies than you can press 'M' and move the model as per your own requirment and size of the Frame that you want.

![Description](https://drive.google.com/thumbnail?id=1V7gpfdLM_jXp2iMiqrONX_-Kydes_mKR&sz=w800)

Then after that you can create a sketch on the base of on of the pattern body and then make a two rectangle that will touch the outer edges of the patterns.

![Description](https://drive.google.com/thumbnail?id=18XaI2ze1_8oz9wkKLtPhVOOeMF0j4qVM&sz=w800)

and once you are done then you use the offset feature (availabe in sketch mode) and select the line to make a copy of that line to indicate the outer edge of the frame.

## Body

Then once you are done with the sketch of the walls of the frame then we can select the outer profile (boundary) and extrude it to the height little higher than the height of the pattern body.

![Description](https://drive.google.com/thumbnail?id=1w_FYwnpMynD87p_RlaOZW6TKft97EItL&sz=w800)

Once the extrude is complete it will look something like this.

![Description](https://drive.google.com/thumbnail?id=1n2NYoQm85pLdaybbYdTNxuBHQgfUmaaN&sz=w800)

- make sure the operation in this case is join

After the edges its time to make the base of the frame and to make that select the inner profile of the previous sketch and extrude about 2 or 3mm.

![Description](https://drive.google.com/thumbnail?id=1xTlOqto4LAqr-R3yRHv-Hi8C6Gz4uzVX&sz=w800)

- make sure the operation in this case is join
